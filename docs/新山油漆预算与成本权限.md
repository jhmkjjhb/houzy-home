# 新山油漆预算与成本权限

## 预算计价

新增13项墙面、天花、围墙、金属组件、木门／门框及基层处理预算价。成本与加价配置由公司受控数据库维护，普通报价页面只读取预算售价。

- 提供低位、中位、高位预算售价，默认中位。综合单价按配置计算后四舍五入到分，再乘本次工程量。
- 墙面、天花及金属等按实际涂刷平方尺计，木门与门框按整数套数计，不用房屋建筑面积代替涂刷面积。
- 新报价中已选的室内墙面、天花与外墙自动使用专项价。其他项目在“必答问题”或“价目表”的“新山油漆专项预算”中添加。
- 旧报价保留原价，须明确点击“应用新版油漆预算价”后才更新。各单保存售价快照，后续同步也需用户确认。
- 综合包价不虚构材料／辅材／人工拆分，不再套用旧油漆配方或重复加材料损耗。总价、工序合计、付款分期、打印及CSV包含独立综合工料汇总。
- 原报价器设计费、管理费、优惠及SST设置仍按原规则处理；专项单价不替代这些已存在的整单设置。
- 同范围重复选项必须填写独立范围。金属粉刷与基层处理不会互相自动选择，选择重叠范围时须明确是否另计，不能默认重复套价。
- 带“+”的深度除锈价格不是封顶价。预算可以预览，但正式出单前需获授权人员在“授权现场核价”中确认现场单位成本，由服务器计算核定售价。

## 真实成本权限

- 未登录、客户和未授权普通员工不能读取成本表或成本RPC。店长、区域经理、总经理及管理员默认可查看。
- 总经理／管理员可以在成本弹窗中单独授权和撤销普通员工；店长可查看但不能自行授权他人。
- 权限以服务器中的在职账号、角色和明确授权记录为准，不相信浏览器传入的角色。
- 成本弹窗只在内存和当前授权界面中显示。关闭、退出或切换账号时清除；迟到的请求不能在退出后重新显示成本。
- 本机报价、售价快照、打印、CSV和材料采购核对不包含原始成本或加价字段。

## 价格数据与发布

`supabase/quote_painting_prices_migration.sql` 只包含结构和权限，不包含公司的真实成本行。真实数据通过受控的 `supabase/private/` 文件导入，该目录已加入Git忽略，不能提交到公开仓库。测试使用合成成本，不是公司实际成本。

正式数据库新增两张独立价目／授权表和对应RPC，不修改原合同、整装收款、商品订单或员工角色。权限验收的临时授权在事务内回滚。

## 验证

- `tests/quote-painting-db.mjs`：重复迁移、加价／分币计算、公开售价字段、原始表拒绝、普通员工拒绝、店长查看、管理层授权／撤销、离职／客户拒绝和现场核价校验。
- `tests/quote-painting-browser.cjs`：13项售价、原房间油漆联动、综合合计、档位选择、付款按分一致、开放上限拦截、现场核价、授权界面、报价／打印文档／CSV无成本、退出账号的迟到响应保护、旧报价需手动应用及手机布局。

数据库测试通过 `RENO_PGLITE_MODULE` 指定PGlite模块；浏览器测试通过 `PLAYWRIGHT_MODULE` 和 `RENO_BASE_URL` 指定隔离测试环境。浏览器测试不会使用真实成本或业务账号。
