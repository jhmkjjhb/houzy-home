# 员工整装界面与自动导览修复

## 客户导览

原导览首次等待9秒，自动切换章节时没有滚动定位，且按钮可能早于事件绑定出现，用户容易认为没有反应。

本版在事件就绪后展示按钮；点击立即定位当前章节，显示固定播放状态和6秒倒计时，每次自动切换都将内容滚动到可见区域。支持固定控制条暂停、末页重新播放和完成提示。手动操作、填写／提交签署及切到后台仍会暂停，不触发任何付款、签署、工程完成或验收命令。

## 员工整装页面

沿用客户页与现有HOUZY品牌的深松绿、香槟金、米白底及衬线标题。员工整装列表、新建及项目详情接入统一工作台布局，包含当前加载项目数量、合同／姓名／地址搜索、状态筛选、无结果提示、独立项目档案及固定章节导航。紫色仍用于识别整装业务。

章节跳转保留URL中的项目凭证；打开不同项目回到顶部，同项目保存刷新保留位置。手机端折叠桌面侧栏，表单、按钮及收款摘要适配窄屏。统计仅包含当前权限内最近加载的最多200个项目，不冒充全库数量。

## 验证与范围

`tests/renovation-customer-browser.cjs` 验证即时反馈、内容可见、倒计时、6秒切换、暂停后不继续切换、末页重播、完成提示及原有真实签署／刷新保护。

`tests/renovation-workspace-browser.cjs` 验证员工桌面与390px手机列表、详情、新建、搜索、筛选、清空、返回及章节导航；320px无整页横向溢出。两者均以隔离模拟接口运行，不访问真实客户数据。

相关脚本语法、合同保存、客户操作及签名输入专项检查通过。本次只修改前端，未修改数据库、合同金额、收退款规则或访问权限。上线后另行核对资源版本、真实客户导览和未登录员工跳转。
