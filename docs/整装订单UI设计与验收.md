# 整装订单界面 · 2026-10-25

本次范围：员工整装订单列表、新建项目及项目详情。客户查单与客户签署页不在本次改版范围。

沿用 `portal/houzy-brand.css` 的 HOUZY 品牌变量和原员工后台字体：深松绿侧栏、香槟金边线、米白背景、衬线标题。紫色保留为整装标签及履约状态识别色；普通操作使用系统深绿，新建入口使用香槟金。

## 页面行为

- 项目概览统计当前权限内、当前加载的项目。后端原有查询上限为最近200条，不将其冒充全库统计。
- 按合同编号、姓名或地址搜索，按项目状态筛选；无匹配时可以清除筛选。
- 每项目保留一张主单，金额显示当前应收，进入档案查看合同、增项、收款、履约及验收。
- 详情提供固定章节导航，跳转不会覆盖URL内的项目UUID；打开不同项目回到顶部，同项目收款等刷新保留滚动位置。
- 手机隐藏桌面侧栏，使用品牌顶部栏和横向章节导航；输入框16px，收款摘要两列展示。
- 独立 `workspace.css` 仅在员工整装页面加载；未改动共享品牌文件，也未修改业务RPC或数据库规则。
