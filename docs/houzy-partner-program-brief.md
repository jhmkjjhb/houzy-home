# HOUZY HOME 合作伙伴招募：待确认事项

## 当前页面定位

`partner.html` 面向有意经营家居展厅、经销产品或承接设计施工与项目渠道的潜在伙伴。页面只收集合作意向，具体合作模式由双方沟通并书面确认。

页面可核对的现有内容：HOUZY HOME 的 Mount Austin 地址、官网展示的产品方向、合作意向联系人及 WhatsApp 入口。页面中的厨房图片是产品效果图，没有用作展厅实拍或合作业绩证明。

## 当前表单边界

访客填写后，网页只生成 WhatsApp 草稿；访客须在 WhatsApp 确认发送。网站没有保存或自动转发资料，也没有配置后台线索库。若要统计申请量、分配负责人或自动回访，需要另行设计并启用合规的留资流程。

参考 [Signature 的经销招募页](https://signature.my/be-a-dealer/#dealershipenquiry) 的信息顺序：合作理由、适合对象、意向表单。HOUZY 页面采用自己的品牌视觉和已知业务事实；未沿用参考页的规模、收益或支持承诺。
