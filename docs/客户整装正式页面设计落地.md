# 客户整装正式页面设计落地

2026-10-25。根据已确认的客户互动演示，将五章节绿金设计落实到正式客户页面代码。

## 已实现

- 原有 `portal/renovation-customer.html#项目凭证` 和带增项签署参数的链接继续使用，无需改变门店发给客户的入口。
- 查看合同、付款进度、增项确认、工程进度、验收质保五个章节；保留项目地址、合同号和当前应收总额。
- 自动导览只切换章节，不模拟付款、不填签名、不完成工程或验收；客户操作表单时暂停导览。
- 合同通过现有私有文件函数获取120秒链接，继续校验HTTPS、Supabase域名和项目合同路径。
- 实际付款继续使用现有共用汇总与分期接口；付款计划不算实收，待核对现金不计入已付。
- 客户只能在专属增项链接签署；保留姓名、手写笔迹、确认勾选、内容摘要及服务器校验，正式页面没有“填入演示笔迹”或模拟确认按钮。
- 手机切换章节会按可见宽度重绘签名，尚未提交的姓名、笔迹及勾选不因切换丢失；刷新碰到项目范围变化时保护正在填写／提交的签署。
- 刷新失败保留上次内容并显示未同步提示，不伪造零余额；链接撤销后隐藏原档案。
- 质保按真实验收日期和部件期限计算；未知期限明确待核对。

## 新增只读接口

`supabase/renovation_customer_progress_migration.sql` 提供 `renovation_customer_progress_view(uuid)`。

仅有效非草稿项目凭证可读；只返回项目状态、验收日期、版本及本项目执行分组的名称、状态和更新时间。排除作废执行单和未签／已作废增项，不返回负责人、客户手机号、内部日志、金额、签署凭证或笔迹。

工程进度以“完成分组数／总分组数”展示，明确不等于工程量百分比。接口未部署或网络失败时显示待同步提示，不影响合同等其他章节。
