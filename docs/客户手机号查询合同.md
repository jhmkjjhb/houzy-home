# 客户通过手机号查看整装合同

客户入口：`https://houzyhome.com/portal/customer.html`。

## 门店操作

1. 在整装主单登记含国家区号的业主手机号，例如 `+60101234567`。
2. 上传合同、核对清单和质保，确认双方已签署的有效合同。草稿不会出现在客户查询结果。
3. 主单详情点击“复制客户手机号查询资料”，将登记手机号、合同查阅码和客户入口交给业主或授权联系人。按钮仅复制，不自动发送消息。
4. 客户选国家区号，填写登记手机号和合同查阅码，点击“查询我的整装合同”。结果只展示匹配的整装主单，点开查看合同原件、清单及质保。

## 访问规则

- 手机号是查询依据，不是身份凭证。完整合同必须同时提供私有查阅码，不能凭知道一个电话号码就查询他人的签名、地址及工程资料。
- 查阅码不是短信验证码；本版本不发送短信，不依赖短信服务商。查阅码来自随机项目访问凭证，按合同分别发放；同一手机号的不同合同使用各自查阅码。
- 号码和码不匹配、合同未确认时，统一显示无匹配结果，不透露其他项目。
- 手机号支持国家区号、本地号码、空格和常见分隔符；完整国际号码不会重复加区号。原商品查单不再降级到裸本地号码查询。
- 客户页面仍可使用原项目专属链接；新手机号入口取得的是同一项目的查看权限。
- 已签合同PDF仍在私有bucket，客户查看时由 `renovation-contract` 验证私有项目凭证后签发2分钟临时链接。客户端不能指定文件路径、其他项目或文件存储桶。
- 店长可使旧客户链接及查阅码失效；已签发的PDF短链最多仍可使用2分钟，已下载文件不受链接撤销影响。
- 页面不展示厂家成本、利润、内部操作记录或其他客户资料。

## 数据库与服务

- `supabase/renovation_phone_lookup_migration.sql`：规范化完整国际手机号、手机号＋查阅码匹配，只返回匹配主项目摘要及查看凭证。
- `supabase/functions/renovation-contract/index.ts`：私有PDF查看服务，仅允许受控请求体、有效UUID凭证、已确认合同和本项目下的PDF；响应禁止缓存。
- 不向网页下发service role密钥；函数使用Supabase运行时内置环境变量。

## 合同选择修复

新建项目尚未保存时也能选择PDF并识别清单。补齐业主资料、保存项目后保留已选文件；核对后点击“保存核对版本”才会归档。离开未保存页面仍会提示。

## 验证

- `node tests/renovation-core.cjs`：金额、范本识别、质保及手机号规范化。
- `node tests/renovation-contract-function.mjs`：凭证格式、来源、请求体大小、项目路径、120秒链接及无缓存。
- `tests/renovation-database.mjs`：42项检查，包括仅手机号、错误号码／查阅码、草稿和撤销旧码均拒绝访问。
- 浏览器模拟验证：手机号＋码只展示一张匹配主单，换手机号即清除旧结果；原商品查询完整区号正确，390px无横向溢出。
- 生产数据库已运行可自动回滚的手机号权限测试，没有留下测试项目。
