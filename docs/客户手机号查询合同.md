# 客户通过手机号查看整装合同

客户入口：`https://houzyhome.com/portal/customer.html`。

## 当前访问方式

按业务负责人明确要求，取消客户查阅码限制：选择国家区号、填写登记手机号，点击“查询订单”，同页展示蓝色商品订单和紫色整装订单。已确认的整装单可直接打开合同、清单、金额及质保；无需输入查阅码。

手机号不是身份认证，知道登记手机号的人可以查看对应的已确认合同。草稿仅显示单号与“待门店确认”，不能查看合同明细。

## 门店操作

1. 登记客户手机号；新订单建议使用完整国际号码，例如 `+60101234567`。
2. 上传、核对合同及清单，确认双方已签署的有效合同。
3. 点击“复制客户手机号查询资料”，将登记手机号和查询入口交给客户；复制内容不再包含查阅码，按钮不会自动发送消息。
4. 客户进入手机号查询页，直接打开对应的紫色整装订单。

## 数据库与服务

- 先应用 `renovation_orders_migration.sql`、`renovation_phone_lookup_migration.sql`、`renovation_customer_orders_migration.sql`，再应用 `renovation_phone_direct_view_migration.sql`。
- `renovation_customer_orders(phone)` 返回匹配订单；非草稿额外返回地址、合同金额及项目查看凭证。兼容旧马来西亚手机号码缺少60或使用本地0前缀；不使用任意号码后缀匹配。
- 旧手机号＋查阅码RPC保留以兼容旧客户端，新客户入口不再调用它。
- 私有PDF仍由 `renovation-contract` 校验项目凭证后生成120秒临时链接。客户端不能指定文件路径或其他项目；没有向网页下发service role密钥。
- 手机号接口不返回厂家成本、利润、客户姓名、银行资料、内部日志、完整内部快照或存储路径。
- 撤销旧客户链接仍有效，但客户可用登记手机号重新取得新链接；撤销链接不再等于取消手机号查阅权限。

## 页面行为

- 首页只保留手机号和统一查询按钮，没有查阅码输入框。
- 修改手机号或区号会清除旧结果并忽略旧请求的迟到响应。
- 商品或整装查询单独失败时，保留另一类结果并说明错误。
- 合同上传、核对、锁定、验收及质保计算规则保持原流程。

## 验证

- 隔离数据库53项检查：迁移可重复、角色权限、合同锁定、旧号码兼容、手机号直接查看已确认合同、草稿无查看凭证、错误国家区号不匹配及内部数据不外发。
- 原合同文件函数校验和客户复制按钮测试继续通过。
- 浏览器验证无需查阅码、商品与整装同页、草稿不开明细、单类失败保留其他结果及390px布局。
