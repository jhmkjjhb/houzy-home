# 整装新增工项与材料单

## 店员操作

- 草稿：展开原清单后选择“新增工项”或“新增材料”，填写名称、数量、单位、单价。清单合计和总价自动重算；付款计划按草稿原比例分摊至分，确认前仍须逐项核对。
- 已确认／履约中：进入整装主单“新增工项与材料单”，选择类别，填写名称、规格、数量、单位、单价、执行分组及付款节点。先预览本次新增金额，再保存。
- 每条增项金额为数量乘单价（四舍五入至分）。保存后为待客户签署，不计入应收、不生成执行单，也不能收款；客户电子签署成功后才更新项目当前应收总额、订单列表和未付余额，并生成独立执行单及有效增项付款节点。
- 原合同快照、PDF和原付款节点金额保留；增项以独立记录显示。原合同分期百分比仍以原合同为基准，增项单列收款。
- 店员按对应增项节点逐笔登记实际进款。已确认收款继续显示绿色。
- 错误增项由店长填写原因作废，保留历史及原节点编号。存在已收款／待核对现金或已安排执行时不能直接作废。已竣工验收项目须另建项目。

## 客户同步

客户显示原合同金额、新增工项／材料合计和项目当前总额，工程清单包含明确标记的增项。增项范围变动后，付款刷新会重新载入最新清单、总额及质保说明；自动刷新仍为30分钟，可手动刷新。

新增项目的质保范围和期限未知时留空，等待双方补充凭证，不自动沿用其他产品质保。查看“原合同PDF”仍打开原归档文件。Excel及打印核对清单包括当前有效增项，作废项不计入金额。

## 数据与权限

`renovation_additions_migration.sql` 增加独立增项表、项目新增合计和生成总额；所有写入通过 `renovation_addition_command`，沿用整装项目门店／区域／创建人权限，锁定主单、校验版本、幂等请求并记录审计。

`current_total = snapshot.net + additions_total`。所有付款总额、按期限额、客户查询和订单列表使用同一有效总额。增项节点编号只增加不复用；作废节点保留标记，避免已登记收款错归其他期数。增项执行单参与竣工验收检查。

此功能是项目增项供料／施工清单，不自动生成仓库出入库、采购付款或税务发票。

## 验证

隔离数据库测试包含增项金额、原合同不可覆盖、工项与材料分类、重复请求、版本冲突、越权、分期收款、取消保护、节点不复用及客户同步。生产检查使用 `tests/fixtures/renovation-additions-smoke.sql`，模拟项目及收款全部事务回滚，不影响真实客户。
